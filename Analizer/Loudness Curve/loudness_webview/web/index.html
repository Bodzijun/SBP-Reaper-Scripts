Smooth gradient relative to Target: blue at −6 LU · cyan at −3 · green at Target · amber at +3 · red at +6. Colors interpolate continuously; these are M/S visual guides, not integrated loudness compliance limits.
Wheel: horizontal zoom · Ctrl+wheel: vertical zoom · Shift+wheel: time pan · Alt+click: seek · Middle drag or Navigate mode: pan both axes. Regions use Render start in project. Waveform uses the matching rendered audio, starting at report time 0; amplitude is independent of the LUFS scale.
Linear mode interpolates control points and uses Smoothing. Step mode holds correction until the next point and bypasses Smoothing for hard boundaries.
Snapshot overlays use report-relative seconds. Compare matching render ranges; different durations are not stretched.
Drag on the graph to shape a limit or the desired output level. Pre volume feeds the limiters; Post volume is a gain envelope: a click adds a point without changing its level; hold and drag to adjust. Optional 3 points adds anchors on either side at the selected ± seconds; its zero line is at Target. The selected editing curve is emphasized; other editing curves are translucent. The colored ribbon (or green line) shows the final estimate. Hidden curves cannot be edited. Right-click or double-click near a control point to remove it. Automatic ratios above 1 compress peaks and lift lows; below 1 expand them.

Reading stem analysis
Up to 8 WAV stems, including supported speaker layouts. Overview shows original M/S and whole-file fingerprints. Use Edit or the source tabs to open a measured stem in the shared curve editor. Each source keeps its own curves, parameters, view, Undo/Redo, measurements and destination. Stem preferences survive reopening; measure the unchanged WAV again to restore its curves. Switch to Master to change stem files or alignment. Positive Start offset places a stem later than the master render; initial export start is master render start plus this offset. Refine and B playback analyze the WAV independently. Choose a destination track and enable its Volume envelope for export. Source switching stops playback. Waveform peaks reload without triggering a new loudness scan; use Refine/Fit after edits. Master Target is a mix reference, not a stem delivery requirement. LUFS curves cannot be added to predict the master; that requires summing aligned audio samples. Overview does not include stem corrections or downstream FX. Rescan after changing WAV files. Cancel preserves previous results. S is unavailable before 3 seconds and M before 400 ms; short-material LRA is less stable.

Reading the constellation
The horizontal axis is scene loudness minus Target. Guides are adjustable references for scenes, not a delivery standard for each scene. Overview uses sampled S medians and P95−P10 spread; its M/S windows may cross scene boundaries. Measure scene audio to reset the loudness meter at each scene boundary. Crest is sample peak minus RMS averaged across channels; PLR is True Peak minus I. LRA is unavailable below 3 seconds and less stable for short scenes. After values model the exported gain curve; downstream FX require a rerender.
PREDICTION / RERENDER COMPARISON
Save a prediction, then load the rerendered report.
Error = current measured M/S minus saved predicted M/S. Project offsets align reports; positive shift moves the prediction later. Only overlapping active M/S samples above −70 LUFS are compared. Silence, missing samples and timeline gaps break the curve. This does not measure integrated loudness accuracy.

What is a library?
A library is the complete collection of your snapshots. It stays in this WebView's local storage when a new report is loaded. Download library saves the collection as one JSON backup; Import library merges that backup with the current collection without duplicating snapshot IDs. Restore returns a snapshot's curves and settings to editing using its matching original source. A session saves source paths, curves, settings and the view for continuing work; it does not include audio. Missing measurements show —. After values are audio-preview measurements or explicitly labelled sampled estimates.
